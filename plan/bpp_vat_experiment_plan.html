BPP + VAT 实验方案

1. 目标

结合 VAT 算法改进 BPP 的 Prompt Encoder：利用单调位置对齐与可微相对偏置（IRPB）约束 Cross-Attention，根除示教学习中的轨迹回溯与死循环缺陷。

2. 总流程

3. 算法定义

\(h_j\) 是第 \(j\) 个示教片段的编码，\(p_t\) 是机器人第 \(t\) 次决策时对齐到的示教位置，\(x_t\) 是当前观测窗口的表示。\(p_t\) 与示教片段 \(h_j\) 使用不同符号。

3.1 对齐位置更新

对齐位置的初始值默认为0；\(p_t\) 是第 \(t\) 次决策在示教中的位置，由上一位置加本次前进步长得到。

\[p_0=0,\qquad p_t=p_{t-1}+\Delta p_t\quad(t\geq1),\qquad \Delta p_t=\operatorname{softplus}(w^{\top}u_t+b)>0.\]

\(u_t\) 是 LSTM 隐藏状态。模型先根据旧位置读出附近的示教内容 \(g_t\)，再结合当前观测 \(x_t\) 更新状态并算出步长。

\[a_{t,j}^{(k)}=\operatorname{softmax}_{j}\!\left(\beta_{\mathrm{align}}^{(k)}(p_{t-1}-j)\right),\quad g_t=\operatorname{Concat}_{k}\!\left(\sum_{j=0}^{N-1}a_{t,j}^{(k)}h_j\right),\quad (u_t,c_t)=\operatorname{LSTM}\!\left([x_t,g_t],(u_{t-1},c_{t-1})\right).\]

3.2 插值相对位置偏置（IRPB）

计算示教片段到 \(p_t\) 的距离，并在相邻分桶间插值，得到对 \(p_t\) 可微的位置偏置。

\[d_{t,j}=p_t-j,\qquad \beta^{(\ell,k)}(d_{t,j})=(1-r)b^{(\ell,k)}_{\operatorname{sgn}(\eta)m}+r b^{(\ell,k)}_{\operatorname{sgn}(\eta)(m+1)}.\]

\(\eta\) 是距离对应的连续分桶位置，\(m\) 是左侧分桶，\(r\) 是插值权重；近距离分桶细，远距离分桶粗。

\[\eta=f(d_{t,j}),\qquad m=\lfloor|\eta|\rfloor,\qquad r=|\eta|-m.\]
\[f(d)=\begin{cases}d,&0\leq d<B/2,\\[2pt]B/2+\dfrac{\log(d/(B/2))}{\log(D/(B/2))}(B/2-1),&B/2\leq d<D,\\[6pt]B-1,&d\geq D,\\[2pt]-f(-d),&d<0.\end{cases}\]

\(B\) 是每侧的分桶数量，\(D\) 是最大分桶距离；\(b^{(\ell,k)}\) 是第 \(\ell\) 层、第 \(k\) 个注意力头的偏置表。到达末桶时只读取末桶。

3.3 远距离惩罚

在 3.2 得到的插值偏置上扣除超出 \(D\) 的距离惩罚，得到最终位置偏置 \(\widetilde\beta\)。

\[\widetilde\beta^{(\ell,k)}(d)=\beta^{(\ell,k)}(d)-\lambda_{\mathrm{MD}}\max(|d|-D,0).\]

偏置表以当前位置附近更高的高斯形状初始化；\(\lambda_{\mathrm{MD}}\) 决定远距离惩罚强度。

3.4 Prompt Encoder 的 Cross-Attention

把 3.3 得到的最终偏置加到 BPP 的内容匹配分数上，计算当前观测对示教片段的注意力。

\[s_{t,i,j}^{(\ell,k)}=\frac{q_{t,i}^{(\ell,k)}\cdot k_j^{(\ell,k)}}{\sqrt{d_k}}+\widetilde\beta^{(\ell,k)}(p_t-j).\]

\(\alpha_{t,i,j}^{(\ell,k)}\) 是归一化后的注意力权重；Prompt Encoder 据此输出给 Diffusion Model 的条件表示 \(z_t\)。

\[\alpha_{t,i,j}^{(\ell,k)}=\operatorname{softmax}_{j}\!\left(s_{t,i,j}^{(\ell,k)}+M_j\right),\qquad z_t=\operatorname{PromptEncoder}(x_t,H,p_t).\]

\(i\) 是当前观测 token，\(j\) 是示教片段，\(M_j\) 是 padding mask。示教分块池化、Prompt Encoder 的 self-attention 和 Diffusion Model 的网络结构保持原样。

3.5 动作生成与训练损失

Diffusion Model 在每次机器人决策中固定使用同一个 \(z_t\)，并用 BPP 原有的噪声预测损失联合训练全部模块。

\[\mathcal L_{\mathrm{diff}}=\mathbb E_{t,\tau,\epsilon}\left[\left\|\epsilon-\epsilon_\theta\!\left(A_t^{(\tau)},\tau,x_t,z_t\right)\right\|_2^2\right].\]

\(z_t\) 每次决策产生一次；Diffusion Model 的去噪步不更新 \(p_t\)。

4. 备注

\(p_t\) 单调递增，为 Cross-Attention 提供随决策步向前移动的位置参考；最终注意力仍由内容匹配与位置偏置共同决定。因此，这一机制不能保证完全消除回溯或死循环：模型仍可能在 \(p_t\) 附近反复关注相近的示教片段，也可能在内容匹配足够强时关注更早的片段。

5. 训练方式

主实验选择端到端联合训练。VAT 对齐模块、BPP Prompt Encoder 和原 Diffusion Model 一起接受 diffusion loss 的梯度。Diffusion Model 的结构与损失不改，但参数继续训练。

  1. 先运行原 BPP，作为同数据、同任务划分下的对照。
  2. 沿用可复用的 BPP 权重；新加入的 LSTM 和 IRPB 单独初始化。
  3. 用连续轨迹窗口训练 VAT 状态递推；窗口内保留跨决策步梯度。长窗口可使用截断反向传播。
  4. 每个决策步的 \(z_t\) 连接到原 Diffusion Model，中间不截断梯度。

冻结 Diffusion Model 并单独训练 VAT 不是主实验：VAT 没有直接的位置标签，而原 Diffusion Model 也需要适应新的条件表示。
