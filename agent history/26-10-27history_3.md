## 方案演变与最终决定

最初计划沿用早期方案：加入 VAT 后端到端更新 BPP，并配套连续训练与诊断。Sariel 随后明确纠正：**原 BPP 权重保持不动，仅训练新增 VAT。**

用户追问是否为最简施工后，方案进一步收窄：

- VAT 仅通过 cross-attention 的位置偏置影响 BPP。
- 去掉 LSTM 特征残差注入。
- 各 cross-attention 层共享一组每头 IRPB 参数；alignment read 使用独立 IRPB 表。共享跨层表属于本实验简化，与论文逐层独立表不同。
- 复用现有 `memory_mask` 加性偏置接口，首轮不重写 attention 或 decoder。
- 保留整个个人源码树；首轮不物理删目录、不精简安装环境、不做无关依赖重构。
- 首轮只做 DrawAnything、单条同序示教、单 GPU、单环境评估、batch=1、FP32、从轨迹起点连续训练；关闭 EMA、分布式、混合精度及不适配的随机 action-MSE。
- 连续采样、跨决策状态、reset、TBPTT 和梯度验证仍是必要工作。
- 后续仍计划扩展机械臂；Sariel 明确保留未来可能进行 BPP + VAT 端到端训练的方向，但不属于当前 frozen 方案。

frozen 指冻结 BPP 权重，不是“文档禁止修改”。

## 学长建议：新增 policy 和 dataset 类

学长建议 `diffusion_unet_policy.py` 与 `draw_image_dataset.py` 的新行为另建 class，不改原来的。Sariel 已同意，并要求同步全部计划文件。

最终计划：

| 原类及文件保持不变 | 新类 | 新文件（相对 train_network） |
|---|---|---|
| `DiffusionUnetPolicy` / `policy/diffusion_unet_policy.py` | `VATDiffusionUnetPolicy` | `policy/vat_diffusion_unet_policy.py` |
| `DrawImageDataset` / `dataset/draw_image_dataset.py` | `VATDrawImageDataset` | `dataset/vat_draw_image_dataset.py` |

优先继承原类，复用原初始化、数据转换、归一化、去噪与动作输出，仅覆盖新增行为。原版 YAML 指向原类；VAT YAML 用 `_target_` 指向新类。

重要实施细节：

- 新 policy 负责序列损失、VAT 状态、冻结和 train/eval 模式、VAT-only optimizer。
- 新 dataset 负责连续采样、序列索引和验证集。父类 `get_validation_dataset()` 会重建原 `SequenceSampler`，不能不检查就继承，否则验证退回单时刻语义。
- 保留原模型属性名/state_dict key，尽量不引入包装前缀。新增 class 与是否冻结参数是两件事。
- 训练入口先由新 YAML 实例化新类，再加载旧 BPP 权重；仅按旧 checkpoint 内原 `_target_` 构造会得到原类，不能据此运行 VAT。
- “不改原类”本次明确针对 policy/dataset 两个文件。Prompt Encoder 接入和 workspace 必要训练组织仍按计划实施，不额外扩成全仓库重构。

## 不能遗失的技术约束

- 原视觉编码器、tokenizer/池化、位置嵌入、Transformer、Diffusion 参数及 buffers/normalizer 保持不变。
- 原 BPP 保持 eval 模式，VAT 单独 train/eval。冻结不等于对整个 Transformer/Diffusion 使用 `no_grad()`；loss 必须经它们回传到 VAT。
- 仅 VAT 参数进入 optimizer。训练前后逐 key 精确比较原 BPP 参数/buffers；整个新 checkpoint 的文件 hash 变化不能说明原权重变化。
- 冻结特征可在 VAT 之前 detach；训练缓存避免直接使用不适合 autograd 保存的 inference tensor。
- 每次机器人决策只更新一次位置，去噪各步共用 z_t。p 初值为零，先读旧位置，再用 LSTM/softplus 更新，再给 cross-attention 加 IRPB。
- 训练参考示教 A 与执行 B 为同任务、同 split 的不同 episode；示教固定，执行从起点连续输入。段内保留梯度，TBPTT 段间 detach，轨迹结束再更新参数。
- 默认 Draw 的观测窗口 2、预测 16、执行 12、prompt chunk 10 是四个不同时间尺度，实际以 checkpoint 配置为准。
- 原绝对位置表长度限制仍存在，不能宣称任意长示教泛化。
- VAT 单调的是对齐位置，不是 cross-attention 权重/峰值或动作。用户原稿曾混淆，三份计划已修正。
- 002 是正常参照，001 是否属于对齐失败仍待确认；正式对比需稳定失败案例，同案例/seed/画板/chunk/停止规则比较。
