## 4. 算法方案与训练逻辑

已读取 `plan/bpp_vat_experiment_plan.html`，当前方案：

- VAT 完整集成进 BPP Prompt Encoder；原 Diffusion Action Decoder 网络结构与原 diffusion loss 保持不变。
- 对齐位置 `p_t = p_(t-1) + softplus(w^T u_t + b)`；默认初始位置为 0。
- 根据旧位置读取示教特征，结合当前观测更新 LSTM 隐藏状态，再产生正向步长。
- 用可微插值相对位置偏置 IRPB，将 `p_t - j` 的偏置加到 cross-attention 内容分数上。
- 近距离细桶、远距离对数粗桶，包含超出最大距离的惩罚；偏置表在当前位置附近以高斯形状初始化。
- 状态跨机器人决策步传递；每个决策步更新一次。Diffusion 的多个去噪步使用固定条件表示，不更新 VAT 状态。
- 加载领域对应的已有 BPP 权重，新 LSTM / IRPB 初始化后端到端联合训练。主方案不冻结 Diffusion 参数。
- 训练需要连续决策窗口，窗口内保留递推梯度；长窗口可用截断反向传播。
- 单调位置 + 软注意力偏置不能保证彻底消除回溯或死循环，需用实验检验。
- 从轨迹中间采样窗口时，不能不加处理地把对齐状态总置为 0；初始化/预热策略尚未实现与确定。
- 原 LIBERO 配置启用 attention sink tokens，它们不对应真实示教片段，IRPB 集成必须专门处理；Draw 默认配置不同。

训练数据理解：

- 参考示教 A 与执行轨迹 B 来自同一任务的不同演示。A 提供完整行为参考，B 提供连续观测及监督动作。
- diffusion loss 间接监督 VAT，不默认存在位置标签。
- 不以 loss 收敛等同于学到正确对齐；需记录位置、注意力和任务表现。
- Draw 与机械臂共用核心代码和方法，但用不同配置、初始 BPP 权重、数据与评价指标，分别训练得到各自参数。
- 仅用绘图训练不能认定能零样本迁移到机械臂；这是另一个更强的研究问题。

## 6. DrawAnything、LIBERO 与示教概念

- LIBERO 是机械臂仿真基准，提供任务、场景、示教、初始状态及成功判定；底层依赖 robosuite / MuJoCo。
- DrawAnything-Sim 是二维绘图环境，不需要用 LIBERO 来显示绘图。
- 两者都形成闭环：环境观测 → BPP 动作预测 → 环境执行 → 新观测。
- 机械臂示教通常使用 HDF5；视频只是可视化，不等于模型完整输入。
- NPZ 是压缩数组容器；学长脚本一条示教保存一个 NPZ。
- Zarr 是分块数组存储，BPP 用 ReplayBuffer 数据和元信息组织多轨迹数据集。
- NPZ → Zarr 需正确转换字段与轨迹/任务元信息，不是改文件后缀。
- 预测默认 16 步动作、执行 12 步再预测；具体以实际 checkpoint 兼容配置为准。
