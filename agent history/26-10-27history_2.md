## 4. 启动与可视化链路

在个人 repo 内运行，输出必须是新目录或空目录：

```bash
bash reproduction/draw_origin.sh \
  --npz /data/yty_vat+bpp_draw/inputs/draw_prompt_002.npz \
  --output /data/yty_vat+bpp_draw/logs/draw_origin/draw_prompt_002/<时间_HKT> \
  --boundary-angle-deg 0 --keep-dataset
```

1. `reproduction/tools/npz_to_draw_dataset.py`：NPZ → 单任务 `prompt_dataset.zarr`。
2. `reproduction/core/run.sh` → `core/evaluate.py`：设置环境、保存 provenance、加载 checkpoint。
3. `env_runner/draw_runner.py`：闭环推理，调用 `predict_action(need_weights=True, average_attn_weights=True)`。
4. `utils/plot_util.py` 的 `PromptAttentionLogger`：从 `obs_encoder_metadata['prompt_with_obs_transfomer_attention_weights']` 收集权重。
5. `utils/attention_vis_v2_util.py`：选中间层、平均当前观测 token，渲染示教网格和彩色边框、数值及 MAX，再与 rollout 合成。attention 在内存传递，没有中转权重文件；本次 `save_attention_weights=false`。
6. `reproduction/verify_results.py` 验证视频；`tools/collect_draw_outputs.py` 提取最终图片。

最终视频：`vis/attention_and_rollout_*.mp4`，布局对应截图 `142855`：上方 rollout，下方示教 attention 网格。

下载使用临时 Python 经 SSH 接收远端内存 ZIP，再解压到本地；没有创建独立传输脚本。002 保留原文件名，同时增加三个简短视频副本方便打开。
